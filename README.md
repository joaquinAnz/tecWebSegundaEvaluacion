# Proyecto de Segunda Evaluación - Tecnologías Web I

## Descripción del Proyecto

Este proyecto es parte de la segunda evaluación del curso de Tecnologías Web I, donde se ha desarrollado una aplicación web utilizando **Vue 3** y **Vite** como herramientas principales. La aplicación consiste en una interfaz que muestra personajes de Star Wars, permitiendo a los usuarios buscar y ver información detallada sobre ellos.

### Funcionalidades principales:
- **Buscador**: Los usuarios pueden buscar personajes por nombre.
- **Tarjetas interactivas**: Cada personaje se presenta en una tarjeta que, al hacer clic, muestra información detallada sobre el personaje.
- **Diseño responsivo**: El diseño está optimizado para verse bien tanto en dispositivos móviles como de escritorio.

## Tecnologías utilizadas

- **Vue 3**: Framework para el desarrollo del frontend.
- **Vite**: Herramienta de construcción y desarrollo para una experiencia más rápida y eficiente.
- **Axios**: Librería para realizar solicitudes HTTP y obtener datos de una API externa (Star Wars API).
- **Bootstrap**: Framework CSS utilizado para el diseño responsivo y los estilos básicos.
